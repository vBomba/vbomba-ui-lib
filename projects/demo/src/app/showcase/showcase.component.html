Toast stack

Mount vb-toast-stack once (fixed corner). Push items with VbToastStackService.show() — each toast auto-dismisses after durationMs (default 5.2s). A thick, high-contrast bar shrinks to show remaining time; pointer hover pauses both the bar and the timer. Newer toasts stack on top with a slight overlap; hover lifts one above the rest.

Empty state

vb-empty-state — required title, optional description and iconClass (Boxicons). Project actions into an element marked vbEmptyActions.

Chatbot

vb-chatbot supports streamed assistant replies via streaming: true (blinking caret, optional composer lock) and a header chatStatus pill (idle, streaming, thinking, busy, etc.). Latency and sources apply after the stream ends. Message list uses a subtle textureBackdrop (muted canvas tint) and textureGrid (line pattern) default to true; use [textureGrid]="false" for tint only, or [textureBackdrop]="false" for a flat panel.

Popup

vb-popup renders an animated dialog with highlighted header, close icon, and projected footer actions.

This popup uses the same surface, border, action, and focus tokens as the rest of the library. The footer below shows the maximum recommended action count.

Paginator

vb-paginator supports direct page input plus previous / next buttons.

Form controls

vb-input, vb-textarea, vb-select, vb-checkbox, vb-toggle, vb-radio-group, and vb-slider use project tokens for control surfaces, focus rings, and selected states.
