vbomba-ui

Component library showcase — buttons, app shell, forms, feedback, and data display.

Buttons

Variants: filled, outlined, text, elevated, icon — primary / warn / disabled. Text: label or content. Optional Boxicons via iconClass (e.g. bx bx-save); icon uses mat-icon-button — set ariaLabel when there is no visible label.

Chips

vb-chip — label or projected text; removable shows a close control that emits remove. Optional removeAriaLabel overrides the default remove announcement.

Loader

vb-loader uses project action and text tokens, with a configurable size and variant (spinner | horizontal) inputs. vb-text-loader supports optional typing, optional dots, and restart trigger via restartKey.

Restart all text loader examples

Connection indicator

vb-connection-indicator — status: connected (green glow), disconnected (red), loading (pulsing amber). Optional size (dot diameter in px).

Chatbot

vb-chatbot supports streamed assistant replies via streaming: true (blinking caret, optional composer lock) and a header chatStatus pill (idle, streaming, thinking, busy, etc.). Latency and sources apply after the stream ends.

Popup

vb-popup renders an animated dialog with highlighted header, close icon, and projected footer actions.

This popup uses the same surface, border, action, and focus tokens as the rest of the library. The footer below shows the maximum recommended action count.

Paginator

vb-paginator supports direct page input plus previous / next buttons.

Form controls

vb-input, vb-textarea, vb-select, vb-checkbox, and vb-toggle use project tokens for control surfaces, focus rings, and selected states.
