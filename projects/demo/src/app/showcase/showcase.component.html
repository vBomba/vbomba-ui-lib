Toast stack

Mount vb-toast-stack once (fixed corner). Push items with VbToastStackService.show() — each toast auto-dismisses after durationMs (default 5.2s). A thick, high-contrast bar shrinks to show remaining time; pointer hover pauses both the bar and the timer. Newer toasts stack on top with a slight overlap; hover lifts one above the rest.

Empty state

vb-empty-state — required title, optional description and iconClass (Boxicons). Project actions into an element marked vbEmptyActions.

Chatbot

vb-chatbot supports streamed assistant replies via streaming: true (blinking caret, optional composer lock) and a header chatStatus pill (idle, streaming, thinking, busy, etc.). Pass conversations + [(conversationId)] for a header vb-select switcher and (newConversation) (plus icon). Host owns thread storage and swaps messages when the id changes. Composer attachments: bind [(attachments)], [sourceOptions], and optional [roleOptions] (amber role chips; at most one attached, always leftmost). The composer is contenteditable: chips sit on the left and text wraps around them; height grows with content. Typing @ opens a menu grouped into Roles and Sources. Type @ plus a fragment to filter; picking a role replaces any previous role. Enable rule later via composerAttachmentKinds (add button). (send) emits VbChatbotSendEvent (text + attachments). Assistant replies support markdown (after streaming), copy, auto-scroll, and a scroll-to-latest control when you read older messages. RAG sources render as multi-fragment cards (optional sourcesCollapsible); hover [n] markers to highlight chips. Like/dislike icons sit in the message header next to the latency bar. Bind feedback / feedbackComment and (messageFeedback) to persist ratings (optional text after dislike). Optional placeholder on the composer (omit or empty to hide). Message list uses a subtle textureBackdrop (muted canvas tint) and textureGrid (line pattern) default to true; use [textureGrid]="false" for tint only, or [textureBackdrop]="false" for a flat panel.
